# SIH26006 - Intelligent Freight Forecasting & Vessel Chartering

**Smart India Hackathon 2026** - Freight Intelligence Platform

## 📋 Project Overview

This is a comprehensive decision-support platform for optimized vessel chartering and bulk cargo procurement from overseas to the East Coast of India. The application helps logistics companies, shipping lines, and cargo importers make proactive chartering decisions using freight forecasting, vessel optimization, port analysis, and risk assessment.

**Problem Statement:** Development of an Intelligent Freight Forecasting Model for Optimized Vessel Chartering and Bulk Cargo Procurement from Overseas to East Coast of India (SIH26006)

## 🎯 Project Goals

1. **Freight Forecasting** - Predict future freight rates using historical data and market trends
2. **Vessel Optimization** - Recommend optimal vessel types based on cargo requirements
3. **Port Compatibility** - Verify vessel compatibility with destination port constraints
4. **Risk Analysis** - Assess multi-factor risks (volatility, congestion, demand uncertainty)
5. **Intelligent Recommendations** - Generate actionable chartering strategies
6. **Alert System** - Real-time notifications on market conditions and constraints

## ✨ Key Features

- 📊 **Freight Rate Forecasting** - Predict rates for the next 7, 14, 30, or 60 days
- 🚢 **Vessel Type Comparison** - Handysize, Supramax, Panamax, Capesize
- ⛴️ **Port Infrastructure Analysis** - 6 major East Coast Indian ports
- ⚠️ **Risk Assessment Engine** - Multi-factor risk calculation
- 💡 **Smart Recommendations** - Personalized chartering strategies
- 🔔 **Alert System** - Priority-based market and operational alerts
- 📈 **Analytics Dashboard** - Route performance, vessel utilization, market trends
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile
