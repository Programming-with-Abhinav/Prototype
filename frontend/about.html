Project overview and details

Project Overview

Intelligent Freight Forecasting & Vessel Chartering

Problem Statement ID: SIH26006
Challenge: Development of an Intelligent Freight Forecasting Model for Optimized Vessel Chartering and Bulk Cargo Procurement from Overseas to East Coast of India

Project Goal:

Move from reactive daily freight-market decisions toward proactive short-term/medium-term chartering decisions using advanced freight forecasting, vessel optimization, port constraint analysis, idle-time management, and comprehensive risk analysis.

Target Users:

  • Logistics companies and freight operators
  • Shipping lines and vessel owners
  • Port authorities and cargo handlers
  • Commodity importers on India's East Coast
  • Supply chain decision-makers

Core Features

📈

Freight Forecasting

Predict future freight rates using historical data analysis and market trends.

🚢

Vessel Optimization

Recommend optimal vessel types based on cargo requirements and market conditions.

⛴️

Port Compatibility

Verify vessel compatibility with destination port infrastructure constraints.

⚠️

Risk Analysis

Assess multi-factor risks including freight volatility, congestion, and demand uncertainty.

💡

Smart Recommendations

Generate actionable chartering strategies based on integrated analysis.

🔔

Alert System

Real-time alerts on market conditions and operational constraints.

Technology Stack

Frontend

HTML5 • CSS3 • Vanilla JavaScript • Chart.js

Responsive, professional dashboard interface with real-time data visualization.

Backend

Java • Spring Boot • Spring Web • Spring Data JPA • Hibernate

Robust REST API backend with clean architecture and separation of concerns.

Database

MySQL

Relational database for storing freight history, vessel data, port information, and recommendations.

Forecasting Module

Prototype: Moving average and linear regression approaches
Future: Machine Learning (Python, scikit-learn, TensorFlow)

Architecture designed to integrate advanced ML models as the platform evolves.

Important Disclaimer

⚠️ Prototype Demonstration Notice:

This application is a prototype demonstration developed for Smart India Hackathon (SIH) 2026 as a proof-of-concept. The following important points apply:

  • All data displayed is sample/demo data for demonstration purposes.
  • Freight forecasts are generated using basic prototype models (moving average, linear regression).
  • Port infrastructure specifications are example values, not official port authority data.
  • Vessel specifications are representative samples, not verified manufacturer data.
  • Risk assessments are based on simplified algorithms for demonstration.
  • Production deployment requires: validated historical data, real-time market feeds, official port specifications, and advanced ML models.

This prototype is for demonstration and educational purposes only. Do not use for actual freight market or chartering decisions.
